# estudos-c 

Repositório criado para organizar meus estudos em linguagem C durante a faculdade.

## Estrutura

### estudos-em-sala
Códigos desenvolvidos durante as aulas, organizados por assunto conforme a ordem de ensino:
- `01-sequenciais` — primeiros programas, variáveis e entrada/saída
- `02-condicionais` — if, else, switch
- `03-repeticoes` — for, while, do-while
- `04-funcoes` — criação e uso de funções
- `05-vetores` — arrays unidimensionais
- `06-matrizes` — arrays bidimensionais

### estudos-pessoais
Códigos que faço por conta própria, explorando e praticando fora das aulas.
